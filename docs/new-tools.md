# 组合动作、取色和搜索命令

在 **设置 → 工具与动作** 新建组合动作：填写名称，选择 1–12 个步骤，调整顺序与失败处理，再选择预览、复制或加入任务匣。截图提字放在第一步；其他本地转换与翻译可以接在后面。保存后，在面板空键上右键选择 **组合动作**。组合动作处理当前选中文字或最近的适用内容，原始内容保留；每一步都能在内容的处理轨迹中查看。预览不执行最后的复制或入匣；包含翻译的组合动作在执行时会发送对应文字。

进入截图后，无需按下鼠标，移动指针即可看到随行放大镜：十字线标出中心像素，同时显示源图坐标、颜色预览、HEX 和 RGB。按 **Shift+C** 复制 HEX，不完成截图；颜色进入剪贴板内容库，也会出现在设置中的最近 24 种取色历史。历史颜色可以再次点击复制。

框选一个二维码，点击 **提取文字**，会同时进行本地文字和二维码识别。即使没有可识别文字，也能得到二维码内容；其中的 HTTP/HTTPS 链接进入“下一步”。只有点击“打开二维码链接”才会打开网页，其他协议保持普通文字。

文本转换共提供 21 项操作，包括 JSON、繁简、全角半角、提取链接/邮箱/电话、按行去重与排序、UTF-8 Base64 和 URL 编解码。URL 编码按组件编码；JSON 格式化保留原数字字面量，避免大整数精度丢失。输入和结果都限制为 20 万字符，超出时显示错误，不截断后复制。

| 搜索输入 | Enter 后的行为 |
| --- | --- |
| `2*(3+4)`、`0.1+0.2` | 复制计算结果。支持括号、正负号、四则运算与余数；不执行代码 |
| `10 cm to m`、`32 F to C`、`1 MiB to B` | 复制换算结果。支持长度、面积、体积、质量、时间、速度、温度和数据量 |
| `fy hello` | 打开已填好原文的翻译窗口，开始翻译 |
| `100 USD to CNY` | 汇率默认关闭；开启后按 Enter 查询、显示数据日期并复制。仅发送币种，使用 Frankfurter 日参考汇率，查询失败不使用虚构数据 |

“下一步”的完整动作列表包含 **AI 总结、改写、解释、写回复**。这些动作复用设置中的 OpenAI 兼容翻译服务。浏览列表不发送内容；点击对应动作后才发送当前这份文字，结果另存并关联处理轨迹。回复只生成可编辑草稿，不会代替用户发送。AI 动作不作为组合动作的后台步骤运行。

本地二维码解码使用 [jsQR 1.4.0](https://github.com/cozmo/jsQR)（Apache-2.0）；繁简转换使用 [OpenCC.js 1.4.2](https://github.com/nk2028/opencc-js)（MIT 与 Apache-2.0，含词库归属说明）。许可原文在 `src/vendor/`，随安装包分发。汇率接口说明见 [Frankfurter 官方文档](https://frankfurter.dev/)。
